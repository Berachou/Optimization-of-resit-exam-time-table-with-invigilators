# Optimization-of-resit-exam-time-table-with-invigilators
This is a user interface and system integration for an exam timetable optimization application using MATLAB, Genetic Algorithm (GA), and Simulated Annealing (SA). t generate conflict-free and optimized exam schedules.

The application was designed to help universities and educational institutions reduce manual scheduling complexity, minimize timetable conflicts, and improve invigilator allocation efficiency.
